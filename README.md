# نوا للبيت · Nawa House

Arabic-first COD store for Saudi women. Three owned home rituals, sold as a brand, not as a dropshipping catalog.

| | |
|---|---|
| Store | https://nawahouse.shop |
| API | https://api.nawahouse.shop |
| Brand | نوا للبيت / Nawa House |
| Stack | Next.js (frontend) + FastAPI (backend) + Postgres on EasyPanel |

`docs/` is the build contract. The `frontend/` and `backend/` folders must follow those files and must not invent a second brand, a second price, or a second checkout.

Start at [docs/00-INDEX.md](docs/00-INDEX.md). The handoff prompt is [docs/CODER-PROMPT.md](docs/CODER-PROMPT.md).
